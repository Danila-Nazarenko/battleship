Battleship is a strategic guessing game traditionally played on a grid. The game combines elements of chance and strategy, making it an engaging experience for players of all ages. Originally a pencil-and-paper game, Battleship has evolved into various board games, video games, and mobile applications. The game continues until player has sunk all of the ships..
